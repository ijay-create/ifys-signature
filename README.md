# Ify's Signature Fried Rice

A responsive React + Vite single-page catering website based directly on the supplied project specification.

## Run
```bash
npm install
npm run dev
```

The project uses:
- React + Vite
- Framer Motion
- Lucide React
- Custom CSS only
- Local SVG food-image placeholders so there are no broken image imports

Replace the SVG placeholders in `src/assets/images/` with real food photos later if desired.
